# ATM / Bank Management System

A desktop banking application built with Python and Tkinter.

<img width="1920" height="1020" alt="Screenshot (196)" src="https://github.com/user-attachments/assets/efd10cb0-ebf2-408b-80f9-71310c13b26a" />

## Features
- Savings and Current accounts
- Deposit, withdraw, and transfer between accounts
- Transaction history
- Admin panel: view, search, edit, and delete accounts

## Run
python main.py

Note: the admin password in the code is for demonstration only.
